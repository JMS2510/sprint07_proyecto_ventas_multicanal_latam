# Proyecto de ventas multicanal LATAM

## 📖 Objetivo
Analizar ventas, margen, canales, categorías, outliers y segmentos usando Python, con el fin de obtener hallazgos de negocio y recomendaciones estratégicas.

## 🛠️ Herramientas utilizadas
- Google Colab
- Python 3
- Pandas
- Matplotlib
- Seaborn

## 📂 Pasos principales del análisis
1. Cargar datos
2. Explorar estructura y calidad
3. Limpiar valores nulos y textos
4. Calcular KPIs (ingreso, margen, ventas)
5. Visualizar con Pandas y Seaborn
6. Detectar outliers
7. Segmentar ventas
8. Comunicar hallazgos

## 📊 Resultados destacados
- **Perú / App / Tecnología**: mayor ingreso total (~26.9M) y margen elevado (~10.1M).  
- **Chile / Tienda Física / Tecnología**: segundo lugar en ingresos (~22.7M).  
- **Colombia / Web / Tecnología**: ingresos relevantes (~15.8M) con margen sólido (~5.0M).  

## ✅ Conclusiones de negocio
- El canal **App en Perú** es el más rentable → se recomienda reforzar campañas digitales en esa región.  
- La categoría **Tecnología** domina en todos los países → oportunidad de expansión y diferenciación.  
- Canales físicos aún aportan ingresos altos en Chile → mantener presencia y optimizar márgenes.
